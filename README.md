# Mycelium

A monitoring hub for all your apps in one place: status, uptime, costs, usage, API calls and access management, plus a live map of every file and data store with a pulse along each line when Claude or the app reads or writes it.

**Status:** design stage. Read the [architecture](docs/architecture.md).

The first monitored app is [Reroute](https://github.com/tristan-pofandt/reroute).
