# Mycelium

A monitoring hub for all your apps in one place: status, uptime, costs, usage, API calls and access management, plus a live map of every file and data store with a pulse along each line when Claude or the app reads or writes it.

**Status:** v1 built (2026-10-31): ingest, live map, panels, owner sign-in and access management; deployment to the homelab is next. Read the [architecture](docs/architecture.md) and the [roadmap](docs/roadmap.md).

Where it is heading: monitoring for any kind of project (apps, games, sales), a security centre with AI-assisted hardening, setup scripts and policy packs generated by the site, and a compliance (RegTech) module. The roadmap explains what is possible, the limits, and the order of work.

The first monitored app is [Reroute](https://github.com/tristan-pofandt/reroute).
